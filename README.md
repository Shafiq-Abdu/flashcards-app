# AI Flashcard Generator (PWA)

Live app: https://shafiq-abdu.github.io/flashcards-app/

## What it does
- Upload PDF/TXT or paste notes
- Generates flashcards (Q/A)
- Study mode: flip, next/prev, shuffle, progress
- Save/export/import decks (localStorage)

## Tech Stack
- Frontend: HTML/CSS/JS (GitHub Pages)
- Backend: FastAPI (Render)
- AI: OpenAI API

## Demo
Paste notes → Generate → Study → Save deck
